# Series 02 - RStudio

This repository contains our work for **Section 2 of Series 02** of the RStudio course.

The main topic of this section is **Statistical Tests**, with a focus on comparing groups of data, choosing appropriate statistical tests, analysing treatment effects over time, and investigating relationships between variables.

## Project Structure

The project is organised using a **master Quarto document** together with separate `.qmd` sub-documents.

The master document contains the main structure of the report and includes the different sub-documents. This allows each section to be developed separately while keeping the final report organised in one document.

```         
Series02-Rstudio/ │ ├── Series02-Rstudio.qmd ├── Series02-Rstudio.html ├── Series02-Rstudio.Rproj ├── README.md ├── LICENSE │ ├── data/ │   ├── PrePost.csv │   └── snore.txt │ └── Sub_documents/     │     ├── Section_2.1/     │   └── section_2.1.qmd     │     ├── Section_2.2/     │   ├── section_2.2.1.qmd     │   └── section_2.2.2.qmd     │     └── Section_2.3/         ├── section_2.3.1.qmd         └── section_2.3.2.qmd 
```

### Main Quarto Document

`Series02-Rstudio.qmd` is the **master document** of the project. It contains the main headings and includes the individual `.qmd` sub-documents.

The complete report is generated by rendering this master document.

### Data

The `data/` folder contains the datasets used in the different sections:

- **`PrePost.csv`** is used to analyse the effect of rehabilitation training by comparing measurements before and after treatment.

- **`snore.txt`** contains anthropometric and qualitative data used to investigate stereotypes related to snoring, alcohol consumption, smoking, sex, weight, height, and BMI.

### Sub-documents

The `Sub_documents/` folder contains the individual sections of the assignment. Each subsection has its own `.qmd` file and is organised into folders according to the corresponding section.

This structure makes the project easier to navigate and allows the different sections to be worked on separately.

## Section 2.1: Statistical Tests

Section 2.1 introduces the main concepts needed to understand and apply statistical tests.

It covers:

- Mean and median

- Variance and standard deviation

- Normal distribution

- Statistical tests

- Parametric and non-parametric tests

- Assumptions of statistical tests

- P-values

- Type I and Type II errors

- Paired and unpaired tests

**File:** `Sub_documents/Section_2.1/section_2.1.qmd`

## Section 2.2: Effect of Treatment Over Time

Section 2.2 uses the `PrePost.csv` dataset to investigate the effect of rehabilitation training on measurements taken before and after treatment.

### 2.2.1 The Data

This subsection describes the dataset and its variables, including:

- What each variable measures

- Units

- Possible values

- Expected changes after rehabilitation

**File:** `Sub_documents/Section_2.2/section_2.2.1.qmd`

### 2.2.2 The Analysis

This subsection analyses whether the treatment had an effect by:

- Comparing measurements before and after treatment

- Checking the distribution of the data

- Selecting an appropriate statistical test

- Performing the statistical test

- Creating a suitable graph

- Interpreting the results

**File:** `Sub_documents/Section_2.2/section_2.2.2.qmd`

## Section 2.3: Testing Some Stereotypes

Section 2.3 uses the `snore.txt` dataset to investigate different stereotypes using anthropometric and categorical data.

### 2.3.1 The Data

This subsection introduces and describes the dataset, including the following variables:

- Age

- Weight

- Height

- Alcohol consumption

- Sex

- Snoring

- Smoking

BMI is calculated from weight and height and is used as a measure of body mass.

**File:** `Sub_documents/Section_2.3/section_2.3.1.qmd`

### 2.3.2 The Analysis

This subsection investigates:

- Whether snorers are fatter

- Whether snorers drink or smoke more

- Whether men are fatter

- Whether women smoke less

- Whether there are correlations between the numerical variables

Different statistical methods are used according to the type and distribution of the data, including:

- Shapiro-Wilk tests

- Mann-Whitney tests

- Chi-squared tests

- Spearman correlations

- Boxplots

- Proportion plots

- Correlation plots

**File:** `Sub_documents/Section_2.3/section_2.3.2.qmd`
